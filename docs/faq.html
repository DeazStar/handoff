Handoff FAQ

Common questions about using Claude Code for job applications with Handoff.

Can Claude Code apply for jobs for me?

It can prepare everything: find jobs, tailor a resume and cover letter, draft the email and fill the form. In Handoff it stops before sending or submitting, and you do that step yourself.

Is Handoff free?

Yes. It is open source under the MIT licence. You need Claude Code, which has its own plan or usage costs.

Does it send my data anywhere?

Handoff runs on your computer: one SQLite file, a dashboard on 127.0.0.1 and an encrypted vault. The assistant (Claude Code) processes the text it works on under your own Claude account, and the assistant visits job sites in a browser.

Will it make things up on my CV?

It is designed not to. Claims must cite facts you wrote, numbers must match, and the server refuses unsupported text. Skills you lack are reported as gaps, not hidden. You should still read everything before you send it.

Does it work for jobs outside software?

Not well yet. The CV rules, skill groups and writing examples are tuned for developer roles. Support for other professions is on the roadmap.

Which systems does it run on?

It is built and used on macOS. Linux should mostly work. Windows is untested.

Can it submit applications automatically?

No, by design. It fills forms and leaves the tab open for you to review and submit.

Does it bypass CAPTCHAs or bot detection?

No. CAPTCHAs are left to you.

What does it need to get started?

Node.js 20 or newer, Claude Code signed in, and a Chromium-based browser. A Gmail app password is optional.

How is it different from other Claude job search projects?

See the comparison in the README. In short, Handoff uses a local database and dashboard and enforces a hard line between what the assistant does and what only you do.
