How to apply for jobs with Claude Code

Claude Code can do most of the tiring work of a job search. This guide shows a safe way to do it with Handoff, an open-source workflow where you approve every step that cannot be undone.

What Claude Code can and cannot do for a job search

On its own, Claude Code can read a job post, compare it with your experience and write a draft. What it should not do unsupervised is send email, submit forms or invent achievements. Handoff adds the missing structure: a local database of facts you wrote, a dashboard, and a hard line between what the assistant does and what only you do.

The steps

  1. Save your facts once. Enter your jobs, projects, education, skills and true statements about your work in the dashboard. Everything the assistant writes comes only from these.
  2. Find jobs. /discover searches the sites you choose, opens each page, checks that the job is still open and scores it against your settings. /add <link> takes links you already have.
  3. Tailor your resume and cover letter. /tailor builds a CV PDF and /cover a letter. Every claim cites a fact and every number must match one. Skills a job wants that you do not have show up as gaps and are never covered up. Each CV gets an ATS-style score with its missing keywords.
  4. Apply by email. /email finds a contact address that is really on the company's page, checks that its domain accepts mail, and drafts the message. You edit and send it from the dashboard.
  5. Apply by form. /apply fills the application form in a real browser and leaves it open. You check it and press Submit yourself.
  6. Follow up. The dashboard reads your mailbox (read-only) for replies, matches them to your jobs and reminds you to follow up.

To do the middle steps in one go, /go <id> takes a job as far as it can and stops for your review.

Why a human stays in the loop

Automated, unreviewed applications tend to contain mistakes and can get you rejected. In Handoff the assistant cannot send, submit, create accounts, type passwords or read your vault. The code enforces this by giving the assistant and the human different interfaces.

What you need

Node.js 20 or newer, Claude Code signed in, and a Chromium-based browser for form filling. A Gmail app password is optional, for sending email and reading replies. Handoff is currently tuned for developer roles and has been built and used on macOS.
